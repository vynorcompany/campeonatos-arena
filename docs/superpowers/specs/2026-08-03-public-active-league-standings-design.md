# Classificação pública de ligas ativas

## Objetivo

Exibir a classificação parcial de categorias públicas no formato Liga enquanto estiverem ativas.

## Regras

- O seletor Ranking exibirá ligas públicas com status publicado ou encerrado.
- Ligas publicadas mostram a tabela calculada a partir dos jogos concluídos até o momento.
- Ligas encerradas mantêm a tabela final.
- Categorias de mata-mata continuam disponíveis apenas depois de encerradas.
- A regra de Ranking geral não muda.

## Validação

Testes cobrirão a inclusão de uma Liga pública ativa e a exclusão de mata-mata ativo. Typecheck e build serão executados antes do envio.
